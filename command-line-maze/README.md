# History of Soccer Maze

## Jaylin Chen

Welcome to my History of Soccer Maze! This maze will take you through a little bit of soccer history and fun facts! Be sure to read each clue and choose the correct directory to continue moving forward. There will be incorrect directories as well which will contain a message telling you to return and try again.

You can start by pressing the the `entrance` directory and opening `clue.txt` for clues.

## Here Are A Few Helpful Commands!

* `ls` — This lists the files and directories in your current location
* `ls -a` — This lists all items, including hidden files and directories too
* `cd folder-name` — This will allow you to enter specific directories
* `cd ..` — This will return you to the previous directory
* `pwd` — shows your current location in the maze
* `cat clue.txt` — This can help show the contents of a clue file

Good luck And Have Fun Exploring!
